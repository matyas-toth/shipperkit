[Shipper](/) is a self-hosted deployment console for the server you own. These docs cover installing it, shipping an application, running it day to day, and recovering when something breaks.

New to Shipper? Start with [Prerequisites](/docs/prerequisites/), [Install](/docs/install/), and [First deploy](/docs/first-deploy/). If you are already down, open the [Recovery runbook](/docs/recovery/).
